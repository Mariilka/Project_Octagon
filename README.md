# Анализ отзывов о компаниях по продаже мебели

Проект практики: по текстам отзывов определить потребности и болевые точки клиентов
мебельных компаний и проверить пять гипотез.

**Данные:** 12 575 отзывов (после очистки) о 381 мебельном магазине Иркутска с 2ГИС,
Яндекс Карт и Google Карт, 2013–2024 гг.

## Результаты

| № | Гипотеза | Вердикт | Главное число |
|---|----------|---------|---------------|
| 1 | Негатив чаще вызван сервисом, чем качеством мебели | **Подтверждена** | сервис затронут в 81,8% негативных отзывов, качество — в 32,2% |
| 2 | Быстрая доставка повышает вероятность положительной оценки | **Подтверждена** (как связь) | 95,8% положительных оценок при доставке в срок против 27,8% при задержке |
| 3 | Главная причина возвратов и претензий — несоответствие описанию | **Не подтверждена** | несоответствие — 18,7% претензий; брак — 47,7%, сроки — 31,6% |
| 4 | Отзывы о мягкой мебели длиннее и эмоциональнее, чем о корпусной | **Не подтверждена** | медиана 30 слов против 37; эмоциональность выше незначительно |
| 5 | Чем выше цена, тем подробнее отзыв | **Не подтверждена**, проверка ограничена | ρ = −0,01 на 192 отзывах с названной суммой |

Полный разбор — в отчёте `report/Отчёт_анализ_отзывов_мебель.docx`.

## Как запустить

```bash
pip install -r requirements.txt
python run_all.py
```

Скрипт выполняет все шаги и пересоздаёт папку `outputs/`.

## Структура

```
data/raw/                  исходные выгрузки (xlsx)
data/processed/            очищенные данные и признаки (создаётся при запуске)
src/prepare.py             шаг 1: объединение и очистка
src/lexicon.py             словари: темы, жалобы, доставка, тип мебели, причины претензий
src/textnorm.py            стеммер Портера для русского языка (опционально — pymorphy3)
src/features.py            шаг 2: разметка отзывов
src/validate.py            проверка словаря на контрольной выборке
src/hypotheses.py          шаг 3: первичный анализ, проверка гипотез, графики
src/export_bi.py           шаг 4: витрина для BI (DataLens)
src/yandexgpt_labeling.py  необязательно: разметка выборки через YandexGPT
validation/control_labels.csv  контрольная разметка 80 негативных отзывов
outputs/results.json       все числа отчёта
outputs/tables/            таблицы по гипотезам (csv)
outputs/figures/           графики (png)
outputs/bi/reviews_bi.csv  витрина для BI-системы
report/                    аналитический отчёт (docx)
```

## Метод

- Тональность — по оценке автора: 1–2 балла — негативная, 3 балла — нейтральная, 4–5 баллов — позитивная.
- Темы, жалобы, скорость доставки, тип мебели, причины претензий и цена извлекаются из текста
  словарями регулярных выражений по основам слов (`src/lexicon.py`).
- Словарь проверен на контрольной выборке из 80 негативных отзывов: точность 0,94 и полнота 0,95
  для жалоб на сервис, 0,86 и 0,89 для жалоб на качество (`python src/validate.py`).
- Статистика: доверительные интервалы Уилсона, тест Мак-Нимара, хи-квадрат и отношение шансов
  (в том числе Мантеля–Хензеля по источникам), критерий Манна–Уитни, регрессия с контролем
  источника и тональности, корреляция Спирмена.
- YandexGPT в основном расчёте не используется. Скрипт `src/yandexgpt_labeling.py` позволяет
  независимо разметить выборку и сравнить со словарём (нужны `YC_API_KEY` и `YC_FOLDER_ID`).

## Аналитический монитор

Дашборд в Yandex DataLens (публичный доступ) — итоги по 5 гипотезам, по чарту на каждую,
фильтры по источнику, компании и году отзыва:
https://datalens.yandex/o1tvez967ihi7

Источник данных дашборда — витрина `outputs/bi/reviews_datalens.csv` (её выгружает
`src/export_bi.py`): одна строка — один отзыв, темы и причины претензий закодированы как 0/1.
В датасете DataLens добавлены вычисляемые поля `Позитив` (оценка ≥ 4), `Негатив` (оценка ≤ 2)
и `Год отзыва`.

## Ограничения

- Отзывы оставляют самые довольные и самые недовольные клиенты; доли описывают отзывы, а не всех покупателей.
- Срок доставки, тип мебели и цена взяты из текста, а не из данных о заказах.
- Разметка словарная; отдельные отзывы размечены неверно, на доли по группам это влияет слабо.

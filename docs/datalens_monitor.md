# Аналитический монитор в Yandex DataLens

Публичная ссылка: https://datalens.yandex/o1tvez967ihi7

## Источник данных

- Подключение `reviews_connection`: загруженный файл `outputs/bi/reviews_datalens.csv`.
- Датасет `reviews_dataset`, вычисляемые поля:
  - `Позитив = IF [Оценка] >= 4 THEN 1 ELSE 0 END`
  - `Негатив = IF [Оценка] <= 2 THEN 1 ELSE 0 END`
  - `Год отзыва = INT([Год])`

Чтобы показать долю по полю-флагу 0/1, у поля ставится тип «Дробное число», агрегация «Среднее»,
формат «Процент».

## Чарты

| Чарт | Тип | Настройки |
|---|---|---|
| Гипотеза 1. Сервис и качество в негативных отзывах | столбчатая | Y: среднее `Жалоба на сервис`, `Жалоба на качество` (в %); фильтры `Негатив = 1`, `Есть текст = 1` |
| Гипотеза 2. Скорость доставки и оценка | столбчатая | X: `Скорость доставки`; Y: среднее `Позитив` (в %); фильтр `Есть текст = 1` |
| Гипотеза 3. Причины возвратов и претензий | столбчатая | Y: средние по четырём полям `Причина претензии: …` (в %); фильтры `Возврат или претензия = 1`, `Позитив = 0` |
| Гипотеза 4. Мягкая и корпусная мебель | таблица | строки: `Тип мебели` (Мягкая, Корпусная); столбцы: количество отзывов, `MEDIAN([Длина, слов])`, `MEDIAN([Индекс эмоциональности])`, доля негативных |
| Гипотеза 5. Цена покупки и длина отзыва | точечная | X: `Цена в отзыве, руб` (логарифмическая шкала); Y: `Длина, слов`; точки: `ID отзыва`; цвет: `Тональность`; фильтр цена ≥ 5000 |

## Дашборд «Монитор: анализ отзывов о мебели»

1. Заголовок и текстовый блок с вердиктами по пяти гипотезам.
2. Селекторы `Источник`, `Компания`, `Год отзыва` (множественный выбор); они фильтруют все чарты.
3. Пять чартов: гипотезы 1–2, 3–4 — парами в ряд, гипотеза 5 — на всю ширину.

Публичный доступ включён в «Поделиться → Публично» вместе со всеми связанными объектами
(чарты, датасет, подключение).
